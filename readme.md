# Python Cyber Password Generator

## Description
A cybersecurity-focused Python script designed to generate highly secure, randomized passwords. This tool helps enforce strong password policies by creating credentials that are resistant to brute-force and dictionary attacks.

## Features
- Generates 12-character high-entropy passwords by default.
- Uses a mathematically randomized selection process via Python's native `random` library.
- Includes a full cryptographic alphabet: lowercase letters, uppercase letters, digits, and special characters (`string.punctuation`).

## How to use
1. Run the script: `python password_gen.py`
2. Copy your newly generated secure password from the terminal.
